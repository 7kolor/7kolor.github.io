## 什么是 7Kolor？

7Kolor 是面向**独立开发者**的情报平台。我们分析数百万条讨论，每周提供：

- 📊 **趋势分析** — 独立开发圈正在发生什么
- 🎯 **痛点信号** — 用户正在为什么困扰
- 🏆 **成功案例** — 什么在做对了，为什么

## 我们的主张

1. **前期洞察 > 闭门造车** — 项目的成败，在写下第一行代码之前就已埋下伏笔。用户需求应该来自真实社区，而不是开发者独自凭空想象。

2. **前 100 个真实用户** — 项目成功的关键，是获得前 100 个真实用户并持续连接。上线后的体验打磨，远比技术栈的选择重要。

3. **AI 时代，选对赛道** — 当 AI 抹平了技术门槛，判断力成为稀缺品。找对赛道、读懂真实需求——这正是情报的价值。

## 六步开发决策流程

从 0 到 1 做产品，先走完这六个决策节点：

| 步骤 | 核心问题 | Slogan |
|------|----------|--------|
| ① 发现机会 | 做什么能赚钱？ | Stop fork repo, start find gap |
| ② 收集信号 | 用户到底在说什么？ | Stop git push, start data pull |
| ③ 深挖问题 | 他们为什么痛苦？ | Stop pull request, start pain research |
| ④ 验证假设 | 我理解对了吗？ | Stop commit, start converse |
| ⑤ 最后把关 | 上线前还漏了什么？ | Stop deploy, start discover |
| ⑥ 验证价值 | 有人愿意买单吗？ | Stop Merge, Start Market |

每个环节都有独立页面：`/steps/step-1/` 至 `/steps/step-6/`。

## 我们提供什么

### 📰 每周情报
每周发布一期报告，涵盖：
- Reddit、Hacker News、IndieHackers、ProductHunt 的热门讨论
- 新兴趋势和情绪变化
- 真实用户痛点和未被满足的需求

### 🔍 定制服务
针对您所在的行业与赛道，我们提供：
- 赛道是否值得进入、目前处于什么阶段
- 用户真正的痛点、以及尚未被满足的需求
- 竞品留下了什么缺口
- 相似赛道里有哪些成功案例、它们做对了什么
